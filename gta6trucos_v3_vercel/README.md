# GTA6Trucos.com — V3

Versión visual preparada para Vercel.

## Diseño
Estética retro-neón original inspirada en la atmósfera costera de los videojuegos de mundo abierto, sin utilizar logos, personajes, capturas ni arte oficial de Rockstar. El logotipo y los iconos incluidos son originales del proyecto.

## Dominio
- https://www.gta6trucos.com
- https://gta6trucos.com

## Deploy
1. Sube este proyecto a GitHub.
2. Importa el repositorio en Vercel.
3. En Vercel > Settings > Domains añade gta6trucos.com y www.gta6trucos.com.
4. En tu registrador crea los registros DNS que Vercel indique.
5. Verifica Search Console con el sitemap.

## YouTube
La V3 deja la sección preparada para conectar YouTube Data API en una función serverless. No se incluye ninguna clave.

## Monetización
ads.txt es deliberadamente un placeholder hasta tener la cuenta real de AdSense y su publisher ID.

## Importante
El sitio es un fan site independiente. GTA, Grand Theft Auto y otras marcas pertenecen a sus titulares. No utilizar material filtrado ni presentar teorías como hechos.
