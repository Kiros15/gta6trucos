# GTA6Trucos — sitio principal ES/EN

Sitio estático bilingüe con identidad visual rosa/morada y capturas ya integradas. La carpeta `01_GTA6TRUCOS_DEFINITIVO/` es la versión principal del sitio.

Rutas: `/es/`, `/en/`, `/es/equipamiento/`, `/en/equipamiento/`, `/es/guias/`, `/en/guides/` y sus guías de capítulo.

El capítulo 1 incluye una guía editorial con orden de misiones contrastado en fuentes recientes. La ilustración de ruta es una línea temporal original y esquemática, no un mapa del juego.
