# GTA6Trucos.com — V3.2 Definitiva

Portal estático preparado para desplegar directamente en Vercel.

## Incluye
- Homepage renovada con estética retro-neón original.
- Material visual oficial de Grand Theft Auto VI enlazado a las páginas oficiales de Rockstar Games.
- Secciones de trucos, guías, easter eggs, mapa, personajes, vehículos, vídeos y noticias.
- SEO técnico básico: títulos, descripciones, canonical, Open Graph, JSON-LD, robots.txt y sitemap.xml.
- Responsive para móvil, tablet y escritorio.
- Aviso legal y atribución independiente de Rockstar Games.
- `ads.txt` preparado como placeholder hasta disponer del publisher ID real.
- Sección de newsletter preparada para conectar un proveedor de correo.

## Material oficial
La portada y varias tarjetas visuales cargan imágenes publicadas en los canales oficiales de medios de Rockstar Games. Cada bloque de material oficial enlaza a su fuente.

Fuente oficial: https://www.rockstargames.com/VI/media

La atribución no equivale por sí sola a una licencia. Para cualquier explotación comercial de material de terceros debe revisarse la licencia y las condiciones aplicables. No se utiliza material filtrado.

## Deploy en Vercel
1. Sube el contenido de `gta6trucos_v3_vercel` al repositorio de GitHub (o usa directamente esta carpeta como raíz del proyecto).
2. En Vercel importa el repositorio.
3. Si el repositorio contiene la carpeta `gta6trucos_v3_vercel`, establece **Root Directory** en `gta6trucos_v3_vercel`.
4. Añade `gta6trucos.com` y `www.gta6trucos.com` en Domains.
5. Si usas Vercel DNS, configura los nameservers que indique Vercel en el registrador.

## YouTube
La sección de vídeos está preparada para conectar una API de YouTube posteriormente. No se incluye ninguna clave privada.

## Monetización
`ads.txt` es un placeholder y debe sustituirse por el contenido real proporcionado por AdSense u otra red publicitaria cuando la cuenta esté configurada.
